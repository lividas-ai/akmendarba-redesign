# Reusable premium business website template

## Goal

Turn the proven Granit Decor showroom experience into a reusable Codex starter for any business without turning it into a generic theme. A new client project must preserve the premium visual system while replacing every client-specific fact, asset, page, service, product, project, and function with information verified from that client's existing sources.

The template is successful only when a client can compare the new site with the old one and find no missing public information or working capability.

## Non-negotiable content contract

- Import every public page, product, service, category, project, article, legal notice, contact detail, download, and user-facing function that exists in the approved source set.
- Never invent missing services, products, statistics, testimonials, prices, team members, certifications, locations, guarantees, project facts, or business claims.
- If the template contains a section for which the client has no verified content, omit the section completely. Do not leave a placeholder or substitute generic copy.
- If the client has content that the template did not anticipate, create a matching page or section in the template's visual language.
- If the source site has a calculator, selector, configurator, form workflow, filter, account function, or other interactive tool, migrate its visible behaviour and rules. A private integration that cannot be accessed must be recorded as blocked, never simulated as working.
- Every factual statement must point to a source record. Rewrites may improve clarity and conversion, but they may not introduce new factual meaning.
- Release requires a source-to-new-site parity matrix. Every source URL and function must be migrated, intentionally excluded with a reason, or explicitly blocked.

## Visual direction

Named philosophy: **quiet Italian editorial showroom**.

- Image-led, spacious, exact, and restrained rather than card-heavy or decorative.
- White, warm neutral, graphite, and one client-derived accent colour.
- Instrument Sans remains the default interface typeface; expressive display type may be configured only when a verified brand system supports it.
- Square geometry, fine rules, optical alignment, controlled asymmetry, and deliberate editorial crops.
- Motion uses short reveals, transform/opacity transitions, and purposeful menu choreography. No gratuitous parallax, floating badges, counters, or looping ornament.
- Desktop, tablet, and mobile retain the same brand language and content hierarchy. Mobile reorganizes; it does not become a stripped-down second design.

## Locked hero film

For the current template generation, the approved 360-degree kitchen orbit and its responsive derivatives remain template-owned media and are not replaced during client import.

- The film remains visible as the first home viewport for every client copy, including clients in unrelated niches, until the user makes a separate template-level replacement decision.
- The desktop and portrait versions must show the same timeline, camera move, speed, and loop point.
- The video is decorative unless it is verified as the client's own work. Copy must never imply otherwise.
- Muted inline autoplay is requested on load, with a sharp poster and visible play/pause fallback.
- A future client-approved film can replace it only through an explicit template unlock, not an accidental import overwrite.

## Responsive behaviour

- Desktop keeps the two-tier showroom header, image-led mega navigation, full-bleed cinematic hero, and editorial section rhythm.
- Tablet has its own layout rules; it must not inherit an oversized desktop layout or a phone-only stack.
- Mobile keeps the full wordmark, compact visual navigation tiles, cinematic hero, restrained image dimensions, and equivalent actions.
- Supporting media should normally occupy roughly one quarter to two fifths of a phone viewport height. Only the hero may deliberately fill the first viewport.
- All interactive targets are at least 44px, respect safe areas, and remain usable at 320px width and 200% zoom.

## Template boundary

### Locked by default

- Core page shell and editorial layout components.
- Design tokens, typography rules, responsive breakpoints, motion language, accessibility behaviours, and focus states.
- Header, navigation, search shell, footer shell, media treatment, and error/loading states.
- Hero video, poster files, and playback component.
- Content/evidence schema, source inventory, validators, parity gates, and QA scripts.

### Replaced for every client

- Business name, logo, brand accent, metadata, contact and legal details.
- Information architecture, navigation labels, URLs, and footer directories.
- All copy, services, products, collections, projects, articles, images, documents, and structured data.
- Function configuration and any client-specific implementation modules.
- Asset provenance and launch approval records.

## Success criteria

- The original Granit Decor client pack still builds and looks equivalent after separation from the template layer.
- A new client can be created by replacing one client package and its assets rather than editing protected template files indiscriminately.
- Unsupported sections disappear automatically.
- Arbitrary verified pages and registered interactive functions can be added without breaking the global design.
- The validator reports missing evidence, unresolved references, duplicate routes, orphan pages, unapproved media, incomplete functions, and viewport parity failures.
- Production checks pass with no console errors, broken links, horizontal overflow, or inaccessible critical interactions.
