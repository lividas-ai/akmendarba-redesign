# Start a new client website

Open a new Codex task in this project and send:

```text
Use $migrate-client-website.

Create a separate client repository from premium-business-template.
Approved source website: https://client.example/
Approved additional sources: none
Intended domain: not decided

Keep the locked cinematic hero film. Import every evidenced page, fact,
service, product, media asset, download, and public function. Do not invent
missing information. Remove unsupported template sections.
```

Only the approved source website is required to begin. Add files, extra URLs,
client statements, media-rights confirmations, credentials, or the intended
domain when they are available. Codex records unavailable private dependencies
as blocked and asks for the exact missing input instead of simulating success.

Do not attach the template folder to every task. The personal
`migrate-client-website` skill is installed, and this repository remains the
golden master. Each client receives a new repository and deployment.
